# TypeScript Fundamentos

Este é um repositório pessoal de **estudos** sobre os fundamentos da linguagem **TypeScript**.

## 📚 Sobre

Esse projeto foi criado com o objetivo de aprender e praticar os conceitos fundamentais de TypeScript, incluindo tipos, interfaces, generics e outras features da linguagem.

## 🚀 Como Rodar

Para construir o projeto, execute:

```bash
npm run build
```

## 📋 Pré-requisitos

- Node.js (versão recomendada: 16+)
- npm (geralmente vem com Node.js)

## 🔧 Instalação

1. Clone o repositório:
```bash
git clone https://github.com/HttpsKenzoaoki/Typescript-fundamentos.git
cd Typescript-fundamentos
```

2. Instale as dependências:
```bash
npm install
```

3. Construa o projeto:
```bash
npm run build
```

## 📝 Notas

Este é um repositório **pessoal de estudos** e não possui uma aplicação final específica. Seu propósito é servir como um espaço para explorar e aprender os fundamentos do TypeScript.
